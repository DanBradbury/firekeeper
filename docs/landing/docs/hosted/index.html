Licensed, opt-in

Hosted dashboard

The same web dashboard as Firekeeper Server, operated by Lucky Daisy at dashboard.firekeeper.ai. Access comes with a purchased license.

Which one?Get accessWhat is sentTermsMissing signup linkStay local

The Hosted dashboard is licensed and opt-in. It is not the free terminal dashboard, and it is not self-hosted Firekeeper Server. There is no open sign-up and no request-access form. Its legal name in the license terms is Hosted Instance.

Which one is which?

OptionWho runs itWhat you need
Terminal dashboardYou, in a terminal, locally.Nothing. Free and open source. Uploads no transcripts.
Free local modeYou, on this machine: Firekeeper Server on loopback, one user.No license key. See Firekeeper Server.
Self-hosted Firekeeper ServerYou, on a server you control.A Personal, Team, or Enterprise license for remote or shared use. Link a machine with firekeeper login --server URL.
Hosted dashboardLucky Daisy, at dashboard.firekeeper.ai.A purchased license. Access follows the license.

Get access

  1. Buy a license at firekeeper.ai/#pricing.
  2. Check your email for the signup link. It is sent to the address the license is registered to; allow up to one business day.
  3. Open the link and sign in. Existing customers: Sign in.
  4. Run firekeeper login on this machine. With no --server, it links to the Hosted dashboard. Approve the machine in your browser.
  5. Nothing is uploaded yet. Preview what would be sent, then report only the agents you allow: 
    firekeeper backfill --all --dry-run   # uploads nothing
firekeeper report --dry-run           # uploads nothing

See the reporting reference for backfill, report, and daemon install, and firekeeper whoami to check which server and account a machine reports to.

What data is sent

Opt-in reporting uploads session metadata and transcripts after best-effort redaction. Redaction is not a guarantee, and the operator, Lucky Daisy, can read what is uploaded. Read what is uploaded and what is not caught before you turn uploads on, and preview with --dry-run.

Pricing and terms

Access comes with a purchased license. No separate Hosted price is published, and there is no Hosted SLA.

Early-access service. The current Hosted Instance terms still describe an early-access service with no availability, support, or data-retention commitment, and say data may be wiped at any time without notice. See the terms.

I bought a license but didn't get a signup link

Check the inbox for the email the license is registered to, and your spam folder. Allow up to one business day. If it still has not arrived, use the contact form.

If you would rather not upload to us

Use only the terminal dashboard, which uploads nothing, or run Firekeeper Server yourself.
