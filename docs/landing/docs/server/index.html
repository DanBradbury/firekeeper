Firekeeper Server

The commercial firekeeper-server binary that serves the web dashboard: browse, search, and chart sessions reported to it.

Firekeeper Server is a separate product from the Firekeeper CLI. Its source is not in the open-source repository, and it is not covered by the CLI's Apache 2.0 license. The terminal dashboard does not need it.

Free local mode

Run Firekeeper Server on this machine, with no license key, and it runs in free local mode: loopback only, one user, no accounts or tokens, every dashboard feature. It will not bind to a public address or serve other accounts until you add a license.

firekeeper serve

firekeeper serve hands over to the separate firekeeper-server program.

Self-hosted, with a license

For remote or shared use (binding beyond loopback, or using accounts and tokens) you need a Personal, Team, or Enterprise license. See pricing. Link each machine to your server with firekeeper login --server URL.

Or let us run it

The Hosted dashboard is the same web dashboard, operated by Lucky Daisy. Access comes with a purchased license.
