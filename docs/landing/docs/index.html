Firekeeper documentation

One terminal dashboard for your coding agents.

See which agents are working or need attention, read their latest replies, and check token usage. The terminal dashboard is free and open source: launch your agents as usual, then run firekeeper in another terminal.

Works with Claude Code, Codex, GitHub Copilot CLI, Kimi Code, OpenCode, Gemini CLI, and Cursor CLI. No Firekeeper account, server, or wrappers required for the terminal dashboard.

Firekeeper Menu Bar on macOS and the web dashboard are licensed, opt-in offerings. Use the web dashboard in free local mode, self-host Firekeeper Server, or use the Hosted dashboard we operate. Firekeeper Menu Bar · Hosted dashboard · Firekeeper Server.

A dashboard, not a new way to launch agents

Firekeeper discovers Claude Code, Codex, GitHub Copilot CLI, Kimi Code, OpenCode, Gemini CLI, and Cursor CLI. Start them in their own terminals as usual. You do not need wrappers, a background service, or a dashboard account.

The terminal dashboard reads local process information and provider session files without modifying them. Quitting Firekeeper leaves your agents running. It does not host terminal panes, keep remote sessions alive, or send messages to agents for you.

No transcript uploads from the terminal dashboard. Usage and update checks can contact provider services or GitHub. Sending transcripts to a server is a separate, explicit opt-in workflow. See what contacts the network.
