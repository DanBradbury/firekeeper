Firekeeper Menu Bar

A licensed macOS menu bar app for seeing which agents are working or need attention and jumping to their terminals, without opening the terminal dashboard.

What it isWhat it doesInstall and launchLicense

What it is

Firekeeper Menu Bar is a licensed macOS app. It is not part of the Firekeeper CLI and it is not covered by the CLI's Apache 2.0 license. The terminal dashboard stays free, and you do not need Firekeeper Menu Bar to use it.

It is macOS only.

What it does

  • Shows which coding agents are working or need attention.
  • Jumps to an agent's terminal from the menu bar.

It does not launch or wrap your agents. Reply and approve tool calls in the agent's own terminal, as you do today. For the full feature list and a comparison with the other views, see Ways to use Firekeeper.

Install and launch

The install and launch steps for Firekeeper Menu Bar are not documented on this page yet.

The CLI install does not include it. brew install ..., the install scripts, and go install install only the Firekeeper CLI and its terminal dashboard. They do not install Firekeeper Menu Bar.

License

A license is required for full use. Which license tiers include Firekeeper Menu Bar, and whether the same key as Firekeeper Server unlocks it, are still to be confirmed. See pricing for the published license prices.

Licensing does not affect the Firekeeper CLI, which is never license-gated.
