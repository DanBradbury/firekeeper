Using Firekeeper

Keyboard shortcuts

Press ? in a main view for the help overlay in your installed version. Letter shortcuts are lowercase unless shown otherwise.

GlobalProcessesChatOverviewUsage

Global

KeyAction
Tab / Shift+TabCycle between Processes, Overview, and Usage.
?Open help. Any key closes it without running that key's action, except Ctrl+C, which quits.
qQuit from a main view. In chat, return to the previous view instead.
Ctrl+CQuit Firekeeper, including from help or chat. Agents keep running.

Processes

KeyAction
Up / Down or k / jSelect a runtime.
Page Up / Page DownMove half a page through runtimes.
Home / EndSelect the first or last runtime.
EnterExpand or collapse inline details when the bottom session panel is hidden.
cOpen the matched session's chat history.
sSwitch to the runtime's terminal. Platform limits apply.
rRefresh immediately.

Chat history

KeyAction
Up / Down or k / jScroll a line.
Page Up / Page DownScroll a page.
g / GJump to the first or latest message. Uppercase G follows new messages.
rReload the transcript.
Esc / c / qReturn to the view you opened chat from.

Chat is read-only. Return to the agent's terminal to send a message or approve an action.

Overview

Press r to refresh every provider. Use Tab to move to another main view.

Usage

KeyAction
Left / Right or h / lSwitch provider.
Up / Down or k / jSelect a historical session.
Page Up / Page DownMove through sessions in groups of ten.
Home / EndSelect the first or last session.
EnterOpen the selected session's chat.
rRefresh the selected provider.
